# heading-tiers

Obsidian で、見出しの下の本文を親子関係の深さに応じてインデントし、
親見出しごとに縦のガイド線を引くプラグイン。ガイド線は見出しのレベルごとに色が変わる。

- 深さは見出しのレベルではなく、実際の入れ子で決まる。H1 のない H2 だけのノートでも、H2 は左端から始まる
- 見出しの行は親の深さ、本文はその 1 段下に並ぶ
- ライブプレビュー、ソースモード、閲覧モードで効く
- コードブロック、表、コールアウト、数式、リスト、引用、埋め込みもいっしょに下がり、ガイド線は途切れない
- 閲覧モードでも、段落や見出しの間隔は Obsidian 標準のまま
- コードブロックや frontmatter の中の `#` は見出しとして扱わない
- 色の既定値はテーマの色（H1 から順に `--color-red` / `orange` / `yellow` / `green` / `blue` / `purple`）

## 設定（英語）

| 項目 | 内容 |
| --- | --- |
| Enable | 全体のオン・オフ |
| Indent width | 1 段あたりの幅 (px)。既定は 24 |
| Show guide lines | ガイド線の表示 |
| Guide width | ガイド線の太さ (px) |
| Guide colors | `Per heading level`（レベルごと）か `Single color`（1 色） |
| H1〜H6 / Guide color | 色の指定。リセットボタンでテーマの色に戻る |

設定を変えると、開いているノートにすぐ反映される。

ノート単位で無効にするには、frontmatter に次のように書く。

```yaml
---
heading-tiers: false
---
```

ガイド線の濃さは CSS 変数 `--ht-guide-alpha`（既定 55%）で、
親見出しの左端からガイド線までの距離は `--ht-guide-offset`（既定 2px）で変えられる。

## インストール

```sh
npm install
npm run build
```

`main.js`、`manifest.json`、`styles.css` を `<vault>/.obsidian/plugins/heading-tiers/` にコピーし、
設定 > コミュニティプラグイン で有効にする。

STS-indentation や Heading Level Indent など、同じようにインデントするプラグインとは同時に使わないこと（二重に下がる）。

## 制限

- 埋め込んだノート（`![[note]]`）は、埋め込み全体が外側のノートの深さで下がり、中身はそのノート自身の見出し構造でインデントされる
- PDF 出力はまだ試していない

## しくみ

- エディタの行は Obsidian が `margin: 0 !important` を付けていて、リストや引用の行にはぶら下げインデント用のインライン padding がある。
  そのため、行と、表・コールアウト・埋め込みなどのブロックは `translate` でずらし、同じ分だけ幅を縮めている。
  背景やコードブロックの枠もいっしょに動き、クリック位置もずれない
- エディタのガイド線は CodeMirror のレイヤー（テキストの背面）に、ひと続きの区間ごとに 1 本ずつ描いている。
  はみ出しを切り取るブロックや、行に付いた枠線の影響を受けない
- 閲覧モードは、セクションごとに透明な左ボーダーで下げている（上下の余白の重なり方は変わらない）。
  ガイド線は `::after` で描き、前のセクションとの隙間の分だけ上へ延ばしている。表はスクロール領域で `::after` が切れるので、自身の背景として描いている
